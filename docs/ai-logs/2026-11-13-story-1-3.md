Decisions 1 and 2 changed the plan before any code was written (commit 449a6cd): the PRD's FR-13 table, the architecture's AD-14 and AD-15, Story 1.3 in the epics, the Epic 1 context, and an entry in each memlog.

Choices the AI made itself, written in the spec (Edvard can still change them):
- 100 shares per bet, so the hand values are round: the sharp trader makes exactly $2,000.
- The thin wallet wins 20 of its 29 bets. The record looks good but still gets *Not enough data*.

- `make-synthetic` refuses to run outside the repository folder, so it never scatters files.
- `.gitattributes` keeps the Wallet files at LF line endings. Without it, git on Windows would check them out as CRLF and break the "byte-identical" check.
