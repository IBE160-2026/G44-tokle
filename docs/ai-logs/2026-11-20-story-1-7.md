## 3. Bugs found in the AI's code

The AI's own test runs caught three of its mistakes:
- It typed a wrong timestamp into a date test. The test failed; the timestamp was fixed, not the code.
- Seven new tests named only a user journey or Edvard's decision, not an FR, AD or UX-DR number. The project's rule test caught them.
- A helper script turned the `\b` in a regex (a "word boundary" in a search pattern) into an invisible control character, and split two others across lines. The test run caught it, and a scan found no other control characters in the changed files. The same slip happened once more in the spec's own note about it and was fixed the same way.

The three reviewers raised 27 findings, grouped into 22. The AI checked each against the code:
