## 4. Review

Three reviewer helpers read the diff and filed 34 findings in 26 groups: 17 fixed, 2 deferred to Story 3.5, 7 rejected with a reason (all in the spec's triage log). The main fixes:
- **macOS CI would have gone red.** On GitHub's Mac machine the page rightly says "⌘C", but three tests expected "Ctrl+C". The tests now set the platform themselves, and a Safari/Firefox Mac case was added.
- **A likely cause of the one-off failure:** the copy test's fake clock kept running in real time, so a slow machine could pass 2 seconds early. The clock is now paused.
- **"Copied" next to "Copy failed".** A refusal right after a copy left both showing. Fixed, with a test that fails on the old script.
- **The browser itself could reach the network.** The socket block only covers the Python process. Every request a page makes outside the app is now blocked and fails the test.
- **Honest wording:** Playwright brings its own small Node.js helper and `uv sync` installs it (about 40 MB); the README said "nothing is downloaded". Fixed, with a memlog correction.
- **Smaller ones:** "Copied" is now part of the button's name for speech input, high-contrast mode shows hover and focus on the primary button too, the light theme and two more pages are tested, `CI=false` no longer counts as CI.

**Deferred to Story 3.5:** a test of the copy button after a live lookup swaps in the Verdict, and a high-contrast run of the new styles.
