## 5. Bugs found

**Found by real data, in code from earlier stories:**
- The market-record parser from Story 2.1 rejected Polymarket's whole answer when one open market had no prices yet (it happened on 0xd218e4's markets). Any live lookup touching such a market would have failed as "Polymarket did not answer". Fixed: an open market without prices is read with none; a closed one is still refused.
- The offline client looked up each shared market in the first file that had it, so real Wallets (which share markets) made it re-read 10 MB files thousands of times: one Wallet took 68 s instead of 0.4 s. The Synthetic Wallets never share markets, so this never showed before. Found by a new test, fixed, with a test that fails on the old code.

**The AI's own slips:**
- Twice, `git add` on the plan folder also took Edvard's two old, untracked `validation-report.html` files into a commit. Both times it was caught before pushing and the commit was amended.
- Three test checks were first written so that they could not fail (`or True` and the like). They were fixed before the first run.
- A long shell command broke on quoting, as the handoff note had warned. Edits went through script files instead.
- The first build used the zip's outdated pick file (question 5 above).

**The three reviewers** raised 42 findings. The AI checked each against the code: 18 groups fixed, 1 deferred, the rest rejected with reasons. The main ones:

| Found by | Problem | Fix |
|---|---|---|
| Edge-case reviewer | After a pull, old coin-flipper files in `instance/` made the Lookup page crash, hiding the hint to run `load-sample` | The *Real Wallets* list reads file names only. The test fails on the old code |
| Blind and edge-case reviewers | A build failing halfway left `sample_data/real/` half old, half new | Files are written to a staging folder and swapped in only when all 10 pass |
| Blind and edge-case reviewers | `--fetch` could add to an edited additions file and sign it again | It checks the SHA-256 first |
| Verification-gap reviewer | No test pinned the 10 Verdicts recorded in the note | A test per Wallet: Verdict, tested bets, Real PnL |
| Blind reviewer | 0x091596's Real PnL was 17 cents off Story 2.4's value, deferred unexplained | Checked: Polymarket changed the fee rate of 5 of its markets between 20 and 23 November, and the strict fee check uses today's rate. Story 2.7 must use the frozen records |

**One review fix was wrong and was reverted.** Two reviewers said an open market with the price field missing (rather than empty) should still be refused. The AI made that change, but the real build then refused the very market that started this: Polymarket leaves the field out. The AI's first probe had hidden the difference. The change was reverted, and a test now pins both shapes.

Deferred to Story 4.6: its before-the-date windows come from the same capture and may leave the two largest Wallets "not fully read" there too.
