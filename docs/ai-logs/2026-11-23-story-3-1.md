## 4. The build

- `core/skilltest.py` counts `at_or_below`; `core/phrases.py` gets the chart's words and axis amounts ("$50k", "−$200,000 or less", cents kept on a tiny Wallet's axis).
- A new `services/chart.py` turns a result into bar heights, gridlines, ticks and the marker position, so the template only places them.
- The template draws the bars, gridlines and marker line as one SVG that stretches; all text is HTML so it never stretches. Bars and labels are hidden from screen readers; the text alternative says it in words.
- **Checked by eye** with screenshots of the running app (Offline Mode) at 1200 and 600 px, inside 360 and 420 px frames, and in the light theme.
- **AI mistakes caught by the tests**: example amounts with a minus sign in code comments tripped the project's rule that only `core/phrases.py` writes amounts; a test docstring rule caught tests that named no requirement; two of the AI's own test expectations were wrong (the rounded axis is wider than the AI assumed, and one Wallet's "$0" is really −0.00000000000016). The tests were corrected, not the code, after checking the code was right.
- **Seen but not part of this story**: the Verdict header above the chart does not stack on narrow screens, so phone-width pages scroll sideways. This was already so before today; Story 3.4 plans it. Noted in `deferred-work.md`.
