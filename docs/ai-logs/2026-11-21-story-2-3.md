Choices the AI made itself, written in the spec and the memlog:
- When several reasons apply, the first in this order is stored: not fully read, unclear resolution, split or merged, only in activity rows, share gap, sold before resolution, not explained. Data-quality reasons come before the trader's own choices.
- Share gap = |activity bought − listed bought| ÷ the larger of the two, so it stays between 0 and 1.
- A fee within $0.0001 of 0 is a maker fill and counts as exactly 0, so Own Fees are never negative.
- Nothing new is stored. The gaps and fees are worked out again from the snapshot's rows, so the database schema did not change.

## 3. What the checks found

- **Listed bets that vanished.** In Story 2.2's code, a Position on the positions list with no trade rows was dropped without being counted. 0x091596 has 21 of them, outputs of a neg-risk conversion in another Market. They are now counted as "share gap", which puts that Wallet over the 10% note. Story 2.4 may give them a better label (deferred-work).
- **Fees on real data.** On 0x091596, 39 taker fees match the schedule within $0.00001 and 7 maker fills are 0. Only the $44.31 one fails. On 0x0f4b0a, every fee in a 3% Market passes, and the 7 in Markets now at 1% fail.
- **What `total_size` means.** For 98% of partly sold Positions, the list's `total_size` equals shares bought, not shares still held. So the share-gap rule does not wrongly hit partly sold bets.
- **The Gamma fetch** took 4 requests and found all 30 chosen Markets. One split Market turned out to be still open in Gamma, so the window correctly leaves it out, and the test says so.
- **`load-sample`** still loads all 1,005 Sample Wallets (20 s).

## 4. Bugs found in the AI's code

The AI caught some of its own mistakes before the review:
- It first keyed the listed Positions by token id alone. An existing test, which reuses token ids across Markets, failed. Now they are keyed by Market and token.
- Two of its new test expectations were wrong, not the code: a sort order, and the number of split Markets in the window (one is still open).
- Before the review, the AI broke each new rule on purpose, 16 changes in all. Every one made a test fail.

The three reviewers raised 25 findings. The AI checked each against the code:

New test with a 0-share list row |

In total: 6 groups fixed, 2 deferred (the conversion-output label for Story 2.4, and the card's labels and stored Position set for Epic 3), the rest rejected with reasons.
