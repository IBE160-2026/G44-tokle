# Review: verification of the architecture spine (2026-10-21)

Independent reviewer, lens: was each committed decision checked against reality, not assumed from memory. Sources: PyPI JSON, npm, GitHub releases, package source code, docs.polymarket.com, the Data API v2 OpenAPI file, platform.claude.com. No Polymarket data endpoints were called.

**Verdict:** The stack is solid. Every version exists, is the latest release, and works with Python 3.12 to 3.14, and the Anthropic and Flask claims hold. One claim the spine depends on is out of date: Polymarket officially replaced CLOB `/prices-history` on 2026-09-04. The spine also misses a few Data API v2 paging and filter rules.

Status key: **confirmed** = checked and true; **wrong** = checked and false or out of date; **partly** = true but missing a condition; **unverifiable** = cannot be checked without calling the API or waiting.

## Top items to act on

1. **CLOB `/prices-history` has been replaced** by `/v2/prices-history`, which keeps 1-minute data for only about 7 days. The Copy Test depends on minute prices for old buys. Treat this like the v1 retirement: plan the change now.
2. **AD-3's smaller-page retry can't work mid-walk**, because the cursor fixes the page size. Restart the walk, or mark the read partial.
3. **Filters must be sent again on every page**, and **rows with no `last_event_at` drop out of any `start`/`end` window**. Both quietly change which Positions are counted.
4. **Activity read**: handle `CONVERSION` and `is_combo` rows. Check the fee formula on v2 activity rows **before 2026-10-24**, while v1 can still be compared, and check fees against each Market's own `feeSchedule`, not a fixed band.
5. Small hardening: `app.run(load_dotenv=False)`; a case-insensitive Domain enum; explicit `effort` on Haiku; `BEGIN IMMEDIATE`; `--disable-socket` in `addopts`; `uv run pytest` in CI.
