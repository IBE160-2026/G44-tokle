## Intent

**Problem:** An examiner without the network cannot run a Scan: in Offline Mode "Start Scan" is off ("Offline Scans are not ready yet."), `OfflineClient` cannot run the funnel, Offline Mode has no worker, and the stage 2 Synthetic Wallets (steady sharp, forecaster, speed trader) do not exist (FR-13, FR-16, AD-14).

**Approach:** The generator adds the three stage 2 types with price paths and a small fixed set of synthetic anchor Markets; `OfflineClient` becomes a `FunnelClient` serving those Markets and their holder lists from the Sample Wallets' own rows; Offline Mode gets the same job queue and worker as a live run, so the normal Scan runs unchanged and its Watchlist holds at least sharp trader, steady sharp, forecaster and speed trader.

## Design Notes

- Holder rows are derived, not stored: Polymarket computes them from the same trades, so deriving them from the Sample Wallets' rows keeps one source (AD-10) and works unchanged for real Wallets in 4.7.
- Price paths only after the cut-off: the Copy Test samples only after-part Positions (FR-18a); this keeps room under the 50 MB limit for 4.7.
